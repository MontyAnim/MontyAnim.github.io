# Thumbnails Directory

Place your project thumbnail images (GIFs or static images) here.

## Naming Convention

Match the filename in your project's front matter:
- `maya-batch-exporter.gif`
- `water-shader.gif`
- `project-name.gif` or `.png`

## Recommended Specs

- **Format:** GIF (for animations) or PNG/JPG (for static)
- **Dimensions:** 800x600px or 16:9 aspect ratio
- **File Size:** Keep under 5MB for GIFs
- **Content:** Show the tool/shader in action

## Tips

- Use tools like ScreenToGif or LICEcap for creating GIFs
- Optimize with tools like ezgif.com to reduce file size
- Include clear visuals of what makes your project unique
