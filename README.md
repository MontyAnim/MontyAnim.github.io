# MontyAnim.github.io

My personal portfolio website built with Hugo and deployed on GitHub Pages.

## 🚀 Local Development

To run the site locally:

```bash
hugo server -D
```

Then visit `http://localhost:1313` in your browser.

## 📝 Adding Content

- Create new posts: `hugo new content/posts/my-post.md`
- Edit pages in the `content/` directory
- Customize site settings in `hugo.toml`

## 🎨 Theme

This site uses the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

## 🔧 Deployment

The site automatically deploys to GitHub Pages when you push to the `Publish` branch via GitHub Actions.
